# Changelog

## 0.1.0 — first public release

- Native desktop relay explorer, defaulting to Counter-Strike 2.
- Real ICMP measurements, cancellable scans, per-game configuration caching, and saved App ID.
- Interactive world map with individual ping labels, stable camera-relative placement, and GPU-independent fallback.
- Automatic approximate regional focus via ipwho.is, with a persistent off switch.
- Connection overview, relay details, search, filters, and latency sorting.
- Manual GitHub update checks and versioned native release artifacts with checksums.
- Original MatchPing branding and icon, Windows/macOS icon bundles, and a Linux application launcher installer.
- MIT-licensed original workspace and bundled third-party license notices.

Read-only: no firewall changes or forced matchmaking regions. ICMP measurements are not in-game latency. Packages are unsigned; macOS builds are not notarized.
