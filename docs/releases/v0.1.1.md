# MatchPing v0.1.1

The first public release of MatchPing: a native desktop app for exploring Steam relay locations and comparing real connection latency, defaulting to Counter-Strike 2.

This replaces the unpublished `v0.1.0` build. Icon verification now works across Go toolchain versions by comparing artwork pixels rather than PNG compression bytes.

## Included

- Real ICMP relay measurements, cancellable scans, search, filters, and a fastest-reply shortcut.
- An offline-bundled map with country names, high-contrast borders, individual ping labels, and an interactive fallback for GPU problems.
- Automatic approximate regional focus via ipwho.is, with a saved off switch in region settings.
- Editable Steam App ID, per-game configuration caching, and manual GitHub update checks.
- Original MatchPing app icons and MIT-licensed application code.

## Downloads

- **Linux x64:** extract `matchping-linux-amd64.tar.gz`; run `./matchping`. Run `./install.sh` to add a per-user application-menu entry and icon. Requires GTK3, WebKitGTK 4.1, and `ping`.
- **Windows x64:** extract `matchping-windows-amd64.zip`; open `matchping.exe`. Requires WebView2. The executable is a GUI application with an embedded icon.
- **macOS:** choose the Intel or Apple Silicon archive and move the extracted app to Applications.

Packages include license notices. `SHA256SUMS` contains archive checksums.

## Important limitations

MatchPing is read-only: **it does not force matchmaking regions or modify your firewall**. ICMP latency is not in-game latency. No reply does not prove that a relay is offline. Steam’s coordinates can be inaccurate; Windows localized ping output may be unsupported.

Packages are **unsigned**, and macOS apps are **not notarized**. OS trust warnings may appear. Regional focus contacts ipwho.is using your public IP; you can disable future automatic lookups in region settings. No analytics or telemetry are included.
